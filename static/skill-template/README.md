# QA Session Package

This folder is a complete QA test session captured with the QA Smart
Assistant browser extension. It contains everything needed to generate a
professional test report from it — by this extension's own AI report
feature, or by any other AI agent with file access.

## What's here

- `session.json` — structured session data: metadata, the test rules
  checklist, bug annotations with timestamps, and the voice transcript.
- `recording.mp4` (or `.webm`) — the screen recording with microphone
  audio, if one was captured.
- `screenshots/` — PNG screenshots captured during the session, in order.
- `skill/` — the instructions for turning this package into a report.

## How to act on it (for an AI agent reading this)

Read `skill/QA-REPORT-SKILL.md` and follow it. In short: read
`session.json` first, look at the screenshots if present, then write one
complete QA report following the exact structure defined in
`skill/playbooks/report.md`. No clarifying questions — everything needed
is in this package.

Generated by QA Smart Assistant.
